# Installation (Chrome & Edge)

1. Download this folder to your computer.
2. Open **Chrome** (or **Microsoft Edge**):
   - Go to `chrome://extensions` (Edge: `edge://extensions`).
   - Enable **Developer mode** (toggle top-right).
   - Click **Load unpacked** and select the `Cyber OMAN Shield 2040 v1/` folder.
3. Pin the extension (puzzle icon → pin) for quick access.
4. Open **Gmail** in a tab, open any email thread, and you should see a green/red banner appear at the top of the message area with a score and advice.

> No extension login is required. For optional threat lookups, add your own API keys in **Options**.
