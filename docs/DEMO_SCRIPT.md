   - Show `chrome://extensions` → Developer Mode → Load unpacked → select folder.
   - Pin the extension and open Gmail in a new tab.

2. **Open sample email** (20–40s)
   - Paste the sample email text (below) into a new message or send it to yourself.
   - Open the thread; point to the **red banner** and **confidence %**.

3. **Popup & Settings** (20–30s)
   - Click the extension icon → show subject, score, explain line.
   - Open **Options** → toggle Bold/Font size; enable **External API checks** (with your keys) and return to Gmail to show updated banner styling.

4. **Conclusion** (5–10s)
   - Mention privacy stance (local analysis by default) and education goal.
